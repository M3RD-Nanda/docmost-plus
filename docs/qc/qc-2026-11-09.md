## Bukti uji (tanpa sesi, dijalankan di produksi)

- `/api/health` → `{"status":"ok", database up, redis up}`.
- Rate limit login: `401`×10 lalu `429` (throttler aktif, tidak mengunci akun).
- Rate limit `/plus/mfa/verify`: `401`×7 lalu `429` (throttler baru terbukti).
- Semua endpoint Plus tanpa sesi → `401` (`mfa/status`, `api-keys`, `bases`, `ai/chats`).
- `mfaToken` rusak → `401` (sebelum perbaikan: `500` + stack trace di log).
- SSO callback `state` palsu → `302 /login?sso_error=…`.
- Bundle produksi memuat chunk `base-page-*.js` berisi editor kita → Q1 aktif di klien.
- Env produksi terverifikasi: `APP_URL=https://docs.mtrinanda.id`, `OPENROUTER_MODEL=deepseek/deepseek-chat`, `LOG_LEVEL=info`.
- `x-frame-options: SAMEORIGIN` ada; **HSTS tidak ada** pada respons aplikasi (lihat Q10).
- OpenRouter langsung: `openai/gpt-4o-mini` → error "No allowed providers"; `deepseek/deepseek-chat` → menjawab.
